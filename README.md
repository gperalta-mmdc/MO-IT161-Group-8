Project - ProcureIT<br>
<br>
Description :<br>
A paperless procurement solution for a BPO's IT Department, it replaces forms and spreadsheets 
with an end-to-end digital process for managing/tracking assets like laptops, desktops, headsets
and IT equip,ent. Handles hardware requests, manager approvals, deployment, repairs, and device 
returns. Gives staff, managers, and IT staff a system to request, approve, and track every item 
from procurement to return/disposal. It also helps meet 5S standards by clearing out paper-trails 
and keeping hardware records organized in one place.




--------------------------------------
Approvals: Authorization and Tracking

A Purchase Requisition requires approval before funds can be spent. The Approvals feature ensures supervisor or department head review prior to purchasing, providing key operational benefits:

Accountability: Assigns clear ownership by recording who approved each request.

Cost Control: Prevents automatic spending by requiring secondary sign-off.

Visibility: Updates request status to "Awaiting Purchase" so requesters can track progress in real time.

Digital Audit Trail: Replaces physical paperwork by logging all approvals and comments directly in the system.

-------------------------------------
Delivery Receipts: Verification and Inventory Updates

Delivery Receipts verify that physical shipments match agreed Purchase Orders regarding quantity, timing, and condition.

Fulfillment Tracking: Updates order statuses on the Dashboard to confirm completed deliveries.

Early Dispute Prevention: Identifies missing or damaged goods at the receiving dock before invoice processing.

Payment Protection: Provides documented proof of receipt to ensure accounting only pays for verified deliveries.

Inventory Synchronization: Triggers accurate stock-on-hand updates within Inventory & Asset Tagging upon item receipt.
